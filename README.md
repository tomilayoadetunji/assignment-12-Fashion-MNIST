This project applies a feedforward neural network to classify Fashion-MNIST images using TensorFlow/Keras. The dataset contains 70,000 grayscale fashion items across 10 categories. Images were normalized, reshaped, one-hot encoded, and augmented before training. The model consists of a Flatten layer, two ReLU-activated Dense layers with dropout, and a Softmax output layer. After 15 epochs, the network achieved a test accuracy of 81.97%, macro precision of 0.8174, macro recall of 0.8197, and macro F1-score of 0.8106. The model performs strongly on classes like trousers, bags, sneakers, and ankle boots, with expected confusion among visually similar upper-body clothing. This solution demonstrates how neural networks can automate fashion image classification and can be extended with CNNs, transfer learning, or model optimization for improved real-world deployment.
